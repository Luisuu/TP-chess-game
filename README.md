# ♟️ Chess Game – Java & JavaFX

A fully functional chess game with a graphical interface, built in **Java** and **JavaFX** following **OOP principles** and the **MVC design pattern**.

> Group project developed with colleagues for the *Programação Avançada* course at ISEC – Instituto Superior de Engenharia de Coimbra.

## Features

- Complete chess rule validation (legal moves, check, checkmate)
- Pawn promotion
- Undo / Redo of moves
- Graphical user interface with JavaFX
- Unit tests

## Tech Stack

| Category | Tools |
|---|---|
| Language | Java |
| GUI | JavaFX |
| Architecture | MVC, OOP |
| Version control | Git |

## Project Structure

```
src/pt/isec/pa/chess/   → Source code (model, controller, UI)
test/                   → Unit tests
reports/                → Project report
```

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Luisuu/TP-chess-game.git
   ```
2. Open the project in IntelliJ IDEA.
3. Make sure JavaFX is configured in the project.
4. Run the main class.
